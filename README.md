**Password Generator** is a C++ program that creates random passwords based on user preferences. It allows the user to specify the desired password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters. Based on these selections, the program builds a custom character set and uses random number generation to construct a password by selecting characters from this set. It also ensures that at least one character type is selected before generating the password. The program demonstrates important C++ concepts such as strings, conditional statements, loops, user input handling, and random number generation.
